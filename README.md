# Arduino Uno + ESP32 スマートロックシステム

RFID（RC522）とジョイスティックを用いた高度な多機能スマートロックのシステム構成図および配線表です。
このシステムは「Arduino Uno」でコアの認証やUI制御を行い、「ESP32」でWi-FiおよびLINE通信を行う2台構成になっています。

## 1. 必要な部品
- Arduino Uno （メイン制御）
- ESP32 開発ボード （Wi-Fi/LINE通信用）
- RC522 RFIDリーダー
- SSD1306 OLEDディスプレイ（0.96インチ / I2C接続 / 4ピン）
- サーボモーター（SG90など）
- ジョイスティック（QYF-860 または標準的なアナログジョイスティック）
- LED 2個 （緑・赤）と適切な抵抗（220Ω程度）
- ブレッドボード ＆ ジャンパーワイヤー

## 2. 配線表

### 🔌 Arduino Uno と ESP32 の接続 (SoftwareSerial)
Arduino Uno側からESP32側へ認証結果のコマンドを送ります。
⚠️ UnoのTXからESP32のRXへ接続する際、Unoの5V信号をESP32の3.3Vへ直接入れるとESP32が破損する恐れがあります。抵抗分圧やレベル変換モジュールの使用を強く推奨します。

| Arduino Uno | 役割 | ESP32 |
| :--- | :--- | :--- |
| `D2` | Uno RX | `TX0` |
| `D3` | Uno TX | `RX0` (※レベル変換推奨) |
| `GND` | グランド | `GND` |

### 📟 SSD1306 OLEDディスプレイ (I2C)

| OLEDピン | Arduino Unoピン | 備考 |
| :--- | :--- | :--- |
| **VCC** | `5V` (または 3.3V) | モジュールの仕様に合わせてください |
| **GND** | `GND` | |
| **SCL** | `A5` | I2Cクロック |
| **SDA** | `A4` | I2Cデータ |

## 3. 操作方法 (UI仕様)

### 🔓 解錠モード（通常時）
初期画面は**カード解錠モード**です。登録済みのRFIDカードをかざすと解錠されます。
この状態でジョイスティックのボタン(SW)を押すと、**パスワード解錠モード**に切り替わります。パスワードは「上下左右斜め」のジョイスティック入力順序で判定されます。

### ⚙️ 管理モード
解錠に成功してドアが開いている間（5秒間）にジョイスティックのボタン(SW)を押すと**管理モード**へ移行します。

管理モードではジョイスティックを上下に動かして以下の項目を選択できます。
1. **Mode: Register / Delete** 
   - 左右で「登録(Register)」「削除(Delete)」を切り替えます。
   - この状態でカードをかざすと、選んでいる処理が実行されます。
2. **Card: (一覧)**
   - 登録されているカードのUID一覧が表示されます。左右でページ送り（前後のカードを確認）できます。
3. **Change Password**
   - ジョイスティックのボタンを押すと、パスワード変更画面になります。
   - 好きな方向を入力してボタンを押し、確認のためもう一度入力すると新しいパスワードが登録されます。
